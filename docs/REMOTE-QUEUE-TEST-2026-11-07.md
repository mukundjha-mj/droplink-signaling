## Open regressions and release gates

Direct resume is fixed and the cardless combined test passes. Cancellation now interrupts blocked reads and flushes before waiting for bounded SCTP shutdown. Flush drains application data into the bounded transport; durable DLNK ACKs confirm delivery, rather than waiting for every transport acknowledgement at each checkpoint. Final-receipt draining is bounded separately. Direct negotiation uses only host/STUN candidates; TURN allocation is reserved for the explicit relay attempt. Buffer-size experiments were reverted.

The optional full TURN suite still fails: forced route 1 times out gathering ICE or opening the relay channel. An earlier local TURN run passed, so current TURN support must not be declared stable. Private-interface advertising did not fix it and was reverted. Keep I08 open. The passing cardless suite does not skip or relabel this failure; the default full test and its failure log remain available.

Additional gates: queue-level offline/revocation acceptance, default-route public fallback, screen-off cellular queue behavior, network handoff during a file, multi-gigabyte files, receiver startup/tray/installer, and production monitoring/release signing. External TURN remains unconfigured.

The web relay has a 64 MiB per-UTC-day per-process traffic guard, including TLS overhead and both directions. It resets on process restart and is not an account-level billing cap. Render free-instance sleep, bandwidth/build quotas and existing account billing policy still apply.
